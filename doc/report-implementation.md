## 2. Проверка

- **66 автотестов** проходят на SQLite и на PostgreSQL 17 в контейнере. Среди них: паритет копии `extract_static.py` на 20 примерах, сценарий таблицы 12.2 целиком (1 кафедра, 5 преподавателей, 14 работ, 6 к возврату, числа по преподавателям), повторная загрузка, возврат и повторная отправка, копии формы, права всех ролей, отсутствие контактов во всех отчётах кроме 7, API, LDAP (на mock-сервере ldap3), команды управления.
- **Живой стенд** в Docker Compose: вход через HTTPS, загрузка ZIP с 20 примерами (14 ожидают решения, 6 к возврату), фоновая обработка пакета из 21 файла, PDF- и CSV-выгрузки, резервное копирование и восстановление (41 запись → удалено 21 → восстановлено 41).
- **Скриншоты** в Firefox (headless): пакет, предпросмотр, возврат, карточка работы. По ним исправлены отрисовка переключателей и показ полей нового преподавателя.

## 3. Отступления и допущения

- Для разработки используется `compose.dev.yaml`, а не `compose.override.yaml`, как в ТЗ 11.2. Файл override Docker подключает автоматически, и в рабочей среде команда `docker compose up -d` запустила бы режим разработки.
- Вариант В (пакет извлечения) не сделан: для него нужно менять проект формы, а это вне рамок этого проекта. Порядок обновления копии описан.
- Новую кафедру в предпросмотре может создать администратор или ответственный с областью «все кафедры». Ответственный одной кафедры не увидел бы созданную им чужую кафедру.
- Пользователи и роли назначаются в стандартной админ-панели Django (ТЗ 10 это допускает). Из админ-панели убраны контакты студентов, файлы и извлечённый JSON.
- Браузерная версия API отключена: API отдаёт только JSON.

## 4. Не проверено

- Вход через настоящий LDAP/AD-сервер: проверен только mock-сервер ldap3.
- Требования к производительности (ТЗ 11.4) нагрузочным тестом не проверялись.
- Открытие XLSX и CSV в Excel и LibreOffice (критерий 12.3, п. 2): файлы формируются, кириллица в CSV проверена, но в самих программах не открывались.
- Работа в браузерах, кроме Firefox.
- Почтовые уведомления проверены на тестовом почтовом backend Django, без SMTP-сервера.
